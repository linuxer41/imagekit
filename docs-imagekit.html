Guía de Transformación de Imágenes — Parámetros tr

1. Conceptos Básicos

Todas las transformaciones se especifican vía query string ?tr=... en la URL de la imagen. Los parámetros se separan por , y usan el formato clave-valor con guión.

// Formato general
GET /{slug}/{filepath}?tr=param1,param2,...

// Ejemplo real
GET /vendemas/productos/foto.webp?tr=w-800,q-80,f-webp

2. Dimensiones y Recorte

ParámetroFormatoDescripción
ww-{n}Ancho en píxeles
hh-{n}Alto en píxeles
cmcm-{mode}Modo de recorte / ajuste
arar-{num}-{den}Relación de aspecto (se aplica antes del resize)

2.1 Modos de Recorte (cm)

ModoDescripción
forceRedimensiona forzando a las dimensiones exactas (distorsiona si es necesario)
at_maxReduce hasta que quepa dentro de w×h, sin agrandar si es más pequeña
at_leastSimilar a force pero mantiene proporción
max_size_enumSimilar a at_max
maintain_ratioMantiene proporción
pad_resizeEscala para que quepa dentro de w×h y rellena con color de fondo
extractExtrae una región
cropRecorta el centro después de escalar
trimRecorta bordes

3. Fondo Transparente

Para obtener una imagen con fondo transparente se combinan tres parámetros clave:

3.1 Forzar Formato PNG

El formato PNG es necesario porque soporta canal alfa (transparencia). WebP también lo soporta con lossless.

ParámetroEjemploDescripción
ff-pngFormato de salida PNG
ff-webpWebP (usar con lo-true para lossless)

3.2 Color de Fondo con Canal Alfa

El parámetro bg acepta formato RRGGBB o RRGGBBAA. Para transparencia total se usa bg-00000000 (alpha en 00).

ValorDescripción
bg-FF0000Fondo rojo opaco
bg-FFFFFFFondo blanco opaco
bg-00000000Fondo completamente transparente
bg-FF000080Rojo con 50% de opacidad

3.3 Pad Resize + Fondo Transparente

Cuando una imagen no tiene la relación de aspecto deseada, cm-pad_resize escala la imagen para que quepa dentro de w×h y rellena el espacio sobrante con el color bg.

// Imagen rectangular → cuadrada 800x800 con fondo transparente
GET /vendemas/foto.webp?tr=ar-1-1,w-800,cm-pad_resize,f-png,bg-00000000

// Sin ar (rellena según w/h especificados)
GET /vendemas/foto.webp?tr=w-800,h-800,cm-pad_resize,f-png,bg-00000000

// WebP lossless con transparencia
GET /vendemas/foto.webp?tr=ar-16-9,w-1920,cm-pad_resize,f-webp,lo-true,bg-00000000
Comportamiento de pad_resize:
  1. Escala la imagen para que quepa dentro de w×h (usa la escala menor)
  2. Si una dimensión no se especifica, se calcula proporcionalmente
  3. Rellena el espacio sobrante con el color bg
  4. Nunca agranda la imagen (solo escala ≤ 1)
  5. Si la imagen ya es más pequeña, solo la centra sobre el fondo

4. Ajustar a Cuadro (Encuadre)

Para forzar que cualquier imagen se ajuste a un encuadre específico (por ejemplo, cuadrado 1:1) rellenando el espacio sobrante:

4.1 Con Fondo de Color Sólido

// Cuadrado 800x800, fondo blanco
GET /vendemas/foto.webp?tr=ar-1-1,w-800,cm-pad_resize,bg-FFFFFF

// Rectángulo 16:9, 1920x1080, fondo negro
GET /vendemas/foto.webp?tr=ar-16-9,w-1920,h-1080,cm-pad_resize,bg-000000

4.2 Con Fondo Transparente

// Cuadrado 800x800 con bordes transparentes
GET /vendemas/foto.webp?tr=ar-1-1,w-800,cm-pad_resize,f-png,bg-00000000

// 4:3 con fondo transparente
GET /vendemas/foto.webp?tr=ar-4-3,w-800,cm-pad_resize,f-png,bg-00000000

4.3 Recortando en Vez de Rellenar

Si prefieres recortar el sobrante en lugar de rellenarlo, usa cm-crop:

// Recorta el centro para ajustar a cuadrado
GET /vendemas/foto.webp?tr=ar-1-1,w-800,cm-crop

5. Formato y Calidad

ParámetroFormatoDescripción
ff-{formato}Formato: webp, png, jpg, avif, gif
qq-{1-100}Calidad (por defecto: 80)
prpr-trueProgressive (JPEG/PNG)
lolo-trueLossless (WebP — necesario para transparencia en WebP)
mdmd-trueConservar metadatos

Si no se especifica f, el formato se auto-detecta:

  1. Si el cliente acepta AVIF via Accept header → avif
  2. Si el cliente acepta WebP → webp
  3. Si no → usa el default_format del proyecto
Importante: Para preservar transparencia, el formato de salida debe soportar canal alfa. Usa f-png o f-webp con lo-true. JPEG no soporta transparencia.

8. Ejemplos Completos

// 1. Imagen a cuadrado 800x800 con fondo transparente
GET /mi-proyecto/logo.png?tr=ar-1-1,w-800,cm-pad_resize,f-png,bg-00000000

// 2. Thumbnail 300x300, recorte centro, WebP
GET /mi-proyecto/foto.jpg?tr=w-300,h-300,cm-crop,f-webp,q-80

// 3. Banner 16:9, 1920x1080, fondo negro, escala de grises
GET /mi-proyecto/foto.jpg?tr=ar-16-9,w-1920,h-1080,cm-pad_resize,bg-000000,e-grayscale

// 4. Rotar 90°, formato PNG, lossless
GET /mi-proyecto/foto.webp?tr=rt-90,f-png

// 5. Recorte automático de bordes + blur + WebP
GET /mi-proyecto/foto.png?tr=t-10,bl-3.0,f-webp,q-85

// 6. Redimensionar a 400px con calidad 90
GET /mi-proyecto/foto.jpg?tr=w-400,q-90
